## Deskripsi Pengerjaan UTS

**REIONIA Web Store** merupakan website e-commerce untuk brand apparel unisex bernama REIONIA yang menargetkan pasar Indonesia. Website ini menggunakan konsep desain modern dengan kombinasi warna black, white, dan red.

Website dikembangkan untuk memberikan pengalaman berbelanja online, mulai dari melihat katalog produk, memilih ukuran dan warna, memasukkan produk ke keranjang, hingga melakukan checkout dan melihat status pesanan.

Aplikasi dibuat menggunakan HTML, CSS, dan JavaScript.

## Fitur yang Diimplementasikan

### 1. Fitur Pengunjung dan Pelanggan

- Beranda dan katalog produk.
- Pencarian dan filter produk.
- Detail produk, pilihan warna, ukuran, dan stok.
- Registrasi, login, dan logout pelanggan.
- Keranjang belanja.
- Checkout dan pemilihan kurir.
- Buku alamat pelanggan.
- Unggah bukti pembayaran.
- Riwayat dan status pesanan.

### 2. Fitur Admin

- Dashboard pengelolaan toko.
- Pengelolaan kategori dan produk.
- Pengaturan stok berdasarkan warna dan ukuran.
- Pengelolaan pesanan dan nomor resi.
- Verifikasi bukti pembayaran.
- Pengelolaan data pelanggan.
- Laporan penjualan.
- Menu Admin hanya ditampilkan ketika akun admin login.

## Cara Menjalankan Aplikasi

1. Download atau clone repository dari GitHub.
2. Buka folder `2405101098-5E-PROJECT` menggunakan Visual Studio Code.
3. Buka folder `uts`.
4. Jalankan file `index.html` menggunakan ekstensi Live Server.
5. Website REIONIA akan terbuka melalui browser.
6. Pengunjung dapat melihat produk dan melakukan registrasi sebagai pelanggan.
